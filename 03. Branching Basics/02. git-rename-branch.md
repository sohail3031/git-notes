# Git Rename Branch

Renaming a branch in Git means changing the name of a branch while preserving its history and the commits it points to.

The branch remains the same in terms of the code and commit history it tracks; only the **branch reference/name** is changed.

## Rename the Current Branch

If you are currently on the branch you want to rename, use:

```bash
git branch -m new-branch-name
```

### Example

Suppose you are currently on `test-branch` and want to rename it to `test-branch2`:

```bash
git branch -m test-branch2
```

You can verify the new branch name with:

```bash
git status
```

or:

```bash
git branch
```

The current branch will be marked with `*`.

---

## Rename a Branch Without Switching to It

You can rename a branch without first checking it out.

### Syntax

```bash
git branch -m old-branch-name new-branch-name
```

### Example

To rename `test-branch` to `test-branch2`:

```bash
git branch -m test-branch test-branch2
```

Verify the change with:

```bash
git branch
```

---

## Method 1: Rename the Current Branch

### Step 1: Navigate to the Project

Open the terminal and navigate to the root directory of your project:

```bash
cd Desktop/project-name
```

Example:

```bash
cd Desktop/Happy_Messages_Bot
```

### Step 2: Switch to the Branch

Use `git switch` or the older `git checkout` command:

```bash
git switch test-branch
```

or:

```bash
git checkout test-branch
```

### Step 3: Rename the Branch

```bash
git branch -m test-branch2
```

Verify:

```bash
git status
```

or:

```bash
git branch
```

---

## Method 2: Rename a Branch Directly

You do not need to switch to the branch first.

Use:

```bash
git branch -m old-branch-name new-branch-name
```

Example:

```bash
git branch -m test-branch test-branch2
```

Then verify:

```bash
git branch
```

---

## `-m` vs. `-M`

The `-m` option means **move/rename** a branch.

```bash
git branch -m old-name new-name
```

If the new branch name already exists, Git normally refuses to rename the branch. The uppercase `-M` forces the rename:

```bash
git branch -M old-name new-name
```

> [!WARNING]  
> Use `-M` carefully because it can overwrite an existing branch reference.

---

## Renaming a Remote Branch

The commands above rename a **local branch**. If the branch has already been pushed to a remote repository such as GitHub, the remote branch must be handled separately.

For example, after renaming the local branch:

```bash
git branch -m old-branch new-branch
```

Push the new branch and set its upstream:

```bash
git push -u origin new-branch
```

Then delete the old remote branch:

```bash
git push origin --delete old-branch
```

> [!NOTE]  
> Renaming a local branch does **not** automatically rename the corresponding branch on the remote repository.

---

## Quick Reference

|Task|Command|
|---|---|
|Rename current branch|`git branch -m new-name`|
|Rename another local branch|`git branch -m old-name new-name`|
|Force rename|`git branch -M new-name`|
|List branches|`git branch`|
|Check current branch|`git status`|
|Push renamed branch|`git push -u origin new-name`|
|Delete old remote branch|`git push origin --delete old-name`|

## Key Takeaways

- Renaming a branch changes its **name/reference**, not its commit history.
- `git branch -m new-name` renames the **current branch**.
- `git branch -m old-name new-name` renames a **specific local branch**.
- `git branch -M` forces a rename.
- Renaming a local branch does not automatically rename the remote branch.
- If the branch has been pushed to a remote, push the new branch and delete the old remote branch separately.
