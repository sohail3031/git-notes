The `git config` command is used to configure Git and control how Git behaves.

You can use it to configure settings such as:

- User name    
- User email address
- Default text editor
- Other Git preferences

Git configuration can be applied at different levels:

- **System** — applies to all users on the computer
- **Global** — applies to the current user across all repositories
- **Local** — applies only to the current repository

Git uses the configured name and email address to associate commits with an identity.

> [!important]  
> Configuring your Git name and email is one of the first steps you should take after installing Git.

---

## Git Username vs. GitHub Username

Your **Git username** is not the same thing as your **GitHub username**.

The Git username is the name stored in your Git commit metadata.

For example:

```bash
git config --global user.name "Mona Lisa"
```

This name will be associated with future commits created using that Git configuration.

> [!note]  
> Changing your Git username only affects **future commits**. It does not change the author information stored in previous commits.

---

# Setting Your Git Username

## Configure Your Username Globally

A global Git username applies to all repositories for your user account on the computer.

### 1. Open a Terminal

Depending on your operating system, open:

- **Windows:** Command Prompt or Git Bash
- **macOS:** Terminal
- **Linux:** Terminal

### 2. Set Your Git Username

```bash
git config --global user.name "Mona Lisa"
```

The `--global` option means the setting applies to all repositories for your user account.

### 3. Verify the Username

```bash
git config --global user.name
```

Example output:

```text
Mona Lisa
```

---

# Setting Your Git Username for a Single Repository

You can configure a different username for a specific repository.

### 1. Open a Terminal

Open Terminal, Command Prompt, or Git Bash.

### 2. Navigate to the Repository

```bash
cd /path/to/repository
```

### 3. Set the Username

```bash
git config user.name "Mona Lisa"
```

Because `--global` is not specified, this setting applies only to the current repository.

### 4. Verify the Username

```bash
git config user.name
```

Example output:

```text
Mona Lisa
```

# Git Configuration Levels

Git supports multiple configuration levels.

|Level|Option|Scope|
|---|---|---|
|System|`--system`|All users on the computer|
|Global|`--global`|Current user across all repositories|
|Local|`--local`|Current repository only|

For example:

```bash
# System-wide
git config --system user.name "Mona Lisa"

# Global
git config --global user.name "Mona Lisa"

# Repository-specific
git config --local user.name "Mona Lisa"
```

> [!tip]  
> When you run `git config user.name "Mona Lisa"` without specifying a scope, Git uses the repository-level configuration.

# Why Git Needs Your Name and Email

Git records author information in commits.

A commit contains information such as:

- Author name
- Author email
- Commit message
- Timestamp
- Commit identifier

For example:

```bash
git config --global user.name "Mona Lisa"
git config --global user.email "mona@example.com"
```

This information is then used when creating commits.

> [!important]  
> Your Git configuration identifies the author of your commits. It is separate from your GitHub account username.

# Useful Commands

### View Global Username

```bash
git config --global user.name
```

### View Global Email

```bash
git config --global user.email
```

### View Repository Username

```bash
git config user.name
```

### View Repository Email

```bash
git config user.email
```

### View All Git Configuration

```bash
git config --list
```

You can also view configuration together with the file where each setting is defined:

```bash
git config --list --show-origin
```

---

# Key Takeaways

- `git config` is used to configure Git.
- `user.name` defines the name associated with your commits.
- `user.email` defines the email associated with your commits.
- Your Git username is **different from your GitHub username**.
- `--global` applies a setting to all repositories for your user account.
- Repository-level configuration applies only to the current repository.
- Changing your Git configuration affects future commits, not existing commits.
