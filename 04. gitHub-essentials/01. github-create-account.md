# Creating a Personal GitHub Account

To get started with [GitHub](https://github.com/), you need a **personal GitHub account** and a **verified email address**.

Your personal account represents your identity on GitHub. It includes:

- A unique **username**
- A **profile**
- Your GitHub repositories and other contributions
- Your account settings and authentication methods

For example, you can view the [@octocat GitHub profile](https://github.com/octocat).

> [!NOTE]  
> The steps in this guide apply to personal accounts on GitHub.com. They do not apply to **Enterprise Managed Users** or users on **GitHub Enterprise Server**. If an organization created and manages your GitHub account, you can skip this process.

## Creating a GitHub Account

### Requirements

To create a personal GitHub account, you need:

- A GitHub account
- A valid email address
- A verified email address

GitHub provides free personal accounts, with additional paid plans and account types available depending on your needs.

For more information:

- [Types of GitHub accounts](https://docs.github.com/en/get-started/learning-about-github/types-of-github-accounts)
- [GitHub plans](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)

## Sign Up for a New Personal Account

1. Go to [https://github.com/signup](https://github.com/signup).
2. Follow the prompts to create your personal account.
3. Alternatively, you can select **Continue with Google** to use Google social login.
4. Complete the required account information.
5. Verify your email address.

GitHub supports social login with:

- Google
- Apple

> [!NOTE]  
> For Apple users, enabling **Hide My Email** does not prevent GitHub from creating an account when using Apple social login. Using Apple social login can result in the creation of a new GitHub account.

## Email Verification

During the sign-up process, GitHub will ask you to verify your email address.

A verified email address is required for some basic GitHub operations, including **creating a repository**.

If you have problems verifying your email address, refer to GitHub's [Troubleshooting email verification](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/troubleshooting-email-verification) documentation.

> [!IMPORTANT]  
> An email address that is already verified for a **managed user account** cannot be used to create a separate personal GitHub account.

## Personal Account vs. Managed Account

Most individual GitHub users work with a personal account.

However, some organizations create **managed user accounts** for their employees.

|Account Type|Description|
|---|---|
|**Personal account**|Created and managed by the individual user|
|**Managed user account**|Created and controlled through an organization's enterprise environment|

If your company created your GitHub account as an Enterprise Managed User, you generally don't need to create another personal account using the process described here.

## Enable Two-Factor Authentication (2FA)

After creating your account, GitHub recommends configuring **two-factor authentication (2FA)**.

2FA adds an additional layer of security by requiring an additional verification method when signing in.

See GitHub's documentation on [Configuring two-factor authentication](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication).

> [!TIP]  
> Enable 2FA soon after creating your account rather than waiting until you have repositories and other important work associated with the account.
