# Install Git

Git can be installed on the most common operating systems, including **Windows, macOS, and Linux**.

> [!note]  
> Git is often pre-installed on macOS and Linux systems, but you should verify whether it is available before installing it.

## Check Whether Git Is Installed

Open a terminal application:

- **Windows:** Command Prompt or **Git Bash**
- **macOS:** Terminal
- **Linux:** Terminal

Run:

```bash
git version
```

If Git is installed, the command displays the installed Git version. Otherwise, the system will indicate that `git` is not recognized or is an unknown command.

## Install Git Using GitHub Desktop

Installing **GitHub Desktop** also installs Git if Git is not already installed.

GitHub Desktop provides:

- A graphical user interface (GUI) for Git
- A command-line version of Git
- Tools for collaborating with Git repositories

[GitHub Desktop](https://desktop.github.com/)

## Install Git on Windows

### Using Git for Windows

1. Download the latest [Git for Windows installer](https://gitforwindows.org/).
2. Start the installer.
3. Follow the instructions in the **Git Setup** wizard.
4. After installation, open **Command Prompt** or **Git Bash**.
5. Verify the installation:

```bash
git version
```

### Using Git-SCM

[`git-scm`](https://git-scm.com/download/win) is another popular source for downloading Git for Windows.

The Git-SCM download provides:

- The latest Git version
- **Git Bash**
- The Git for Windows installer

The installer is the same [Git for Windows installer](https://gitforwindows.org/) referenced above.

## Install Git on Windows Through Visual Studio Code

[Visual Studio Code](https://code.visualstudio.com/) provides GitHub integration through the **GitHub Pull Requests and Issues** extension.

[GitHub Pull Requests and Issues extension](https://marketplace.visualstudio.com/items?itemName=GitHub.vscode-pull-request-github)

### Setup

1. Create a GitHub account if you do not already have one.
2. Install the **GitHub Pull Requests and Issues** extension.
3. Sign in to GitHub through VS Code.
4. Follow the authentication prompts.

Once GitHub integration is configured, you can perform GitHub-related actions directly from VS Code.

For example, you can clone a repository using:

- **Git: Clone** from the Command Palette (`Ctrl+Shift+P`)
- **Clone Repository** from the Source Control view when no folder is open

[VS Code GitHub documentation](https://code.visualstudio.com/docs/editor/github)

> [!important]  
> Installing the VS Code GitHub extension provides GitHub integration, but Git itself still needs to be installed on your system for Git commands and repository operations.

## Install Git on macOS

Most versions of macOS already include Git.

Verify whether Git is installed:

```bash
git version
```

If Git is not installed, there are several ways to install it.

### Install Git Using an Installer

1. Download a [macOS Git installer](https://sourceforge.net/projects/git-osx-installer/files/git-2.23.0-intel-universal-mavericks.dmg/download?use_mirror=autoselect).
2. Start the installer.
3. Follow the installation instructions.
4. Open **Terminal**.
5. Verify the installation:

```bash
git version
```

> [!note]  
> [`git-scm`](https://git-scm.com/download/mac) is a popular source for obtaining Git on macOS.

### Install Git Using Homebrew

[Homebrew](https://brew.sh/) is a popular package manager for macOS.

If Homebrew is already installed:

1. Open Terminal.
2. Install Git:

```bash
brew install git
```

3. Verify the installation:

```bash
git version
```

## Install Git on Linux

Git was originally developed for managing the Linux kernel source code, so Git is widely supported on Linux distributions.

Git can be installed using the package manager provided by your Linux distribution.

### Debian / Ubuntu

On Debian- and Ubuntu-based systems, Git can be installed using `apt`.

1. Update the package information:

```bash
sudo apt-get update
```

2. Install Git:

```bash
sudo apt-get install git-all
```

3. Verify the installation:

```bash
git version
```

### Fedora

Fedora uses `dnf` as its package manager.

Install Git with:

```bash
sudo dnf install git-all
```

Then verify the installation:

```bash
git version
```

### Other Linux Distributions

For installation instructions specific to other Linux distributions, see the [Git-SCM Linux installation documentation](https://git-scm.com/download/linux).

## Quick Verification

Regardless of the operating system, the easiest way to verify that Git is installed is:

```bash
git version
```

Example output:

```text
git version 2.x.x
```

> [!tip]  
> After installing Git, the next useful step is to configure your Git identity with `git config`, including your username and email address.
